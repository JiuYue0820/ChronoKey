# ChronoKey Bridge (browser extension)

配套 ChronoKey 桌面应用的浏览器扩展（Manifest V3，Chrome / Edge 均可）：
弹出窗口列出与当前标签页站点匹配的登录项，点击自动回填（无密码框时退化为复制密码）。

## 安装（开发者模式加载）

1. 先在 ChronoKey 桌面应用：**设置 → 安全 → 浏览器集成（Beta） → 启用**，复制配对令牌
2. 浏览器打开 `chrome://extensions`（Edge 为 `edge://extensions`）
3. 打开右上角 **开发者模式** → **加载解压缩的扩展** → 选择本仓库的 `extension/` 目录
4. 点击工具栏的 ChronoKey 图标，把配对令牌粘贴进顶部输入框

此后：解锁 ChronoKey → 打开任意登录页 → 点扩展图标 → 选择条目即回填。

## 安全模型（如实说明）

- 通信只有一条路：扩展 → `http://127.0.0.1:39781`，**仅回环地址**，数据不出本机
- 需要桌面应用设置里生成的 **256-bit 配对令牌**（Bearer 头）；令牌可随时重生成（重生成后旧令牌立即失效）
- 请求必须带自定义头 `X-ChronoKey-Bridge: 1` —— 普通网页跨源发不出这个头（预检会被拒绝），所以恶意网站无法探测或调用桥
- 桥只在保险库**解锁期间**工作；锁定的瞬间凭据索引在桌面应用内存中清零
- 限速 120 次/分钟，防令牌爆破
- 默认关闭。桌面应用自身的"拦截一切网络请求"策略不受影响（桥是独立的回环监听，应用自身出站仍为零）

## 局限

- 回填依赖启发式找输入框（密码框 + 邻近用户名框），对不规范的登录页可能失效，此时可点 ⧉ 复制密码
- 未上架商店，需开发者模式加载；签名与商店发布待后续
